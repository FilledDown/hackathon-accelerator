# Inspiration Sources

Use these to look at real interfaces before designing one. With a browser tool, open the site, screenshot the relevant pattern, and describe what makes it work: layout, type, spacing, color, motion. Copy the *idea*, never the assets or copy.

## How to study a reference (5 minutes)
1. Screenshot the hero and one inner section at 1440 wide.
2. Write down the measurable details: max content width, headline size and tracking, body size, number of colors, radius, border vs shadow use, section spacing.
3. Note the one signature move (Linear: product UI as hero with a soft spotlight. Stripe: animated gradient mesh. Raycast: a big glowing brand shape behind centered type).
4. Decide which of those details fit *your* product, and write them into `design/DIRECTION.md`.
